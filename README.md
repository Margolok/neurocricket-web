# NeuroCricket - браузерная версия

Интерактивная модель обхода препятствий с Classical, SNN Rate и SNN Burst.
Посетителю нужен только браузер: устанавливать Python или скачивать проект не требуется.
Расчёты Rate и Burst выполняет настоящая сеть Brian2, а не заранее записанная анимация.

## Использование

1. Выберите карту, алгоритм, seed карты и seed кодирования.
2. Нажмите «Запустить опыт» или «Сравнить три алгоритма».
3. Перемещайте ползунок траектории, изучайте реальные показания сенсоров.
4. Откройте раздел спайков и мембранных потенциалов Brian2.

Запускаются не более трёх опытов с лимитом до 60 секунд модельного времени.
Один сервер выполняет только одну группу опытов одновременно.
Каждый опыт изолирован отдельным процессом с ограничением времени выполнения.
При серверном тайм-ауте результат явно отмечается как неполный.
В бесплатном облаке приложение может засыпать; при первом посещении дождитесь пробуждения.

## Ограничения выводов

Это программная модель, не биологическая копия и не мемристорное оборудование.
Обучения нет, веса фиксированы. Биологическая точность и энергоэффективность не измерялись.
Один запуск не доказывает преимущество алгоритма.

На вкладке исследования показаны отдельно обозначенные сохранённые результаты:
Classical 50/50, Rate 45/50, Burst 47/50; столкновений нет.
Парное сравнение Burst - Rate: +4 п.п. успешности и -0,451 с на 45 взаимных успехах
с равным весом десяти карт. Это описательные результаты, не доказательство
универсального преимущества Burst. Изолированный контроль входа: 335/335 спайков.
В интерактивном сравнении навигации входы могут различаться из-за разных траекторий.

## Развёртывание владельцем

1. Создайте публичный репозиторий GitHub `neurocricket-web`.
2. Загрузите содержимое подготовленной папки публикации в корень репозитория.
   В корне должны быть `streamlit_app.py`, `requirements.txt`, `src/`, `.streamlit/`.
3. В https://share.streamlit.io/ войдите через GitHub и создайте приложение.
4. Укажите свой репозиторий, ветку `main`, файл `streamlit_app.py`.
5. В расширенных настройках выберите Python 3.12. Нажмите Deploy.
6. Убедитесь, что приложение публичное, откройте его `.streamlit.app`-ссылку
   в приватном окне без входа в аккаунт и выполните один опыт.

Пароли, токены и секреты приложению не нужны. В репозиторий не загружаются
исследовательские документы, личные файлы, видео и виртуальное окружение.

Локальная проверка владельцем (не требуется посетителям):

```console
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```
